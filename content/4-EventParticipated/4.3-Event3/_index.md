# Summary Report: "FCAJ - Agentic AI Build"

### Event Objectives

- Introduce participants to real-world applications of Agentic AI built on AWS.
- Share practical experiences from teams participating in the FCAJ Agentic AI Build Week.
- Demonstrate how Amazon Bedrock and AWS AI services can be combined to solve enterprise problems.
- Inspire students and developers to build AI-native applications using modern cloud architecture.
- Encourage knowledge sharing among the AWS community through real project demonstrations.

### Event Information

- **Event Name:** FCAJ - Agentic AI Build
- **Date:** Saturday, July 25, 2026
- **Venue:** 26th Floor, Bitexco Financial Tower, Ho Chi Minh City
- **Organizer:** AWS First Cloud Journey (FCAJ)
- **Format:** Technical Sharing Session & Project Showcase

### Event Activities

Unlike traditional technical workshops, this event focused on sharing real projects developed during the FCAJ Agentic AI Build Week.

Each team introduced a practical Agentic AI solution, explained the business problem, presented the system architecture, demonstrated the application, and shared lessons learned throughout the development process.

Every presentation covered not only AI models but also cloud architecture, AWS services, deployment strategies, cost considerations, scalability, and practical implementation challenges.

This format allowed participants to understand how modern AI applications are designed from both technical and business perspectives.

---

# Key Highlights

## Group 1 – Enterprise Agentic AI Platform

The first team introduced an enterprise-grade Agentic AI platform designed to go beyond traditional chatbots.

Instead of simply responding to user questions, their AI Agent was capable of understanding business goals, planning tasks, interacting with multiple tools, and executing workflows automatically.

One of the most interesting concepts presented was **"Design Once, Deploy Everywhere."**

The team designed a single AI core that could be deployed across multiple communication platforms including:

- Zalo
- WhatsApp
- Telegram
- Instagram
- Future messaging platforms

This architecture significantly reduces development effort while making future expansion much easier.

Another important topic was the difference between traditional chatbots and Agentic AI.

The team explained the complete Agent workflow:

1. Understand the user's goal.
2. Create an execution plan.
3. Select appropriate tools.
4. Execute business actions.
5. Verify the final result before responding.

Unlike conventional chatbots, the AI Agent can actually perform tasks rather than simply generating text responses.

The presentation also introduced a **Value Creation & Delivery Canvas**, showing how AI can help organizations collect evidence, analyze corporate information, detect strategic changes, and support business decision-making through interactive dashboards.

From the technical perspective, the solution utilized multiple AWS services including:

- Amazon Bedrock
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon OpenSearch
- Amazon S3
- Amazon ElastiCache
- Amazon CloudWatch
- Amazon GuardDuty

The presentation demonstrated how combining these services creates a scalable and production-ready Agentic AI platform.

---

## Group 2 – Solution Architect Professional Native App

The second team developed an AI assistant specifically designed for AWS Solution Architects.

The motivation behind the project was that Solution Architects often spend significant time analyzing requirements, drawing architecture diagrams, estimating cloud costs, and preparing documentation.

Their AI application automates many of these repetitive tasks.

Major capabilities include:

- Understanding project requirements written in natural language.
- Recommending AWS architecture designs.
- Supporting Hybrid Cloud architecture planning.
- Automatically generating editable Draw.io diagrams.
- Producing AWS architecture diagrams using official AWS icons.
- Estimating deployment costs in the Singapore Region (ap-southeast-1).
- Identifying missing requirements and architectural assumptions.

During the live demonstration, the team showcased **SignalScout**, an AI assistant capable of collecting business information, analyzing corporate changes, and generating structured reports supported by evidence.

The backend architecture integrated several AWS services including:

- Amazon Bedrock
- AWS Lambda
- Amazon Cognito
- Amazon API Gateway
- Amazon S3
- Amazon DynamoDB
- Amazon CloudWatch
- AWS CloudTrail
- AWS Secrets Manager

The project clearly demonstrated how Agentic AI can improve the productivity of cloud architects without replacing human expertise.

---

## Group 3 – S.H.E.P.H.E.R.D Smart Crowd Monitoring System

The third team introduced **S.H.E.P.H.E.R.D (Smart Human-flow Evaluation, Prediction, Hazard Detection, Response, and Dispatch)**.

Originally planned as their Capstone project, it was later developed during the Agentic AI Build Week to validate the concept under real development conditions.

The objective was to build an intelligent monitoring system capable of:

- Detecting crowd density.
- Monitoring queue conditions.
- Predicting congestion.
- Alerting operators in real time.
- Supporting dispatch decisions using AI Agents.

Computer Vision technologies including **YOLO** and **ByteTrack** were combined with Amazon SageMaker for object detection and tracking.

The intelligent decision layer was powered by:

- Amazon Bedrock
- AgentCore Runtime
- Strands Agent

Video streams were processed through:

- Amazon Kinesis Video Streams
- Amazon ECS
- Amazon ECR
- Amazon SageMaker Endpoint

Supporting AWS services included:

- AWS Lambda
- Amazon S3
- Amazon DynamoDB
- Amazon Cognito
- Amazon CloudWatch
- AWS CloudTrail
- IAM
- AWS Secrets Manager

The project demonstrated how AI can move beyond image recognition to provide intelligent recommendations and real-time operational support.

---

## Group 4 – Adaptive AML Workflow Engine

The final team presented an Agentic AI solution designed for Anti-Money Laundering (AML) investigations.

Financial investigators often spend hours searching multiple databases, verifying customer information, and preparing legally compliant reports.

Their AI workflow engine significantly reduces manual effort by automating investigative data enrichment.

Core capabilities include:

- Collecting information from multiple sources.
- Enriching investigation data automatically.
- Organizing evidence into structured reports.
- Supporting legally compliant documentation.
- Reducing investigation time while improving consistency.

During the live demonstration, the AI automatically gathered relevant information and generated investigation reports through an interactive web interface.

This project illustrated how Agentic AI can be applied to highly regulated industries such as banking and financial compliance, where efficiency and accuracy are equally important.

- Amazon DynamoDB

## Architectural Thinking

One of the biggest lessons from this event was that building AI applications involves much more than selecting a Large Language Model.

Successful AI systems require thoughtful architecture that integrates cloud infrastructure, data management, security, scalability, and business workflows.

Every project demonstrated that AWS services should be selected according to business requirements rather than technological preference.

## Applying to Work

The knowledge gained from this event can be applied to many real-world projects, including:

- Building enterprise AI assistants.
- Designing AI-native cloud applications.
- Developing intelligent monitoring systems.
- Automating compliance workflows.
- Creating scalable Agentic AI platforms on AWS.
- Integrating Amazon Bedrock into enterprise systems.

## Event Experience

Participating in **FCAJ - Agentic AI Build** was an inspiring learning experience.

Instead of theoretical presentations, every team demonstrated complete working systems, explained architectural decisions, and shared real development challenges.

The event highlighted how modern AI applications combine Large Language Models, cloud-native architecture, computer vision, workflow automation, and enterprise services to solve practical business problems.

Listening to experienced builders explain both their successes and technical challenges provided valuable insights that cannot be obtained from documentation alone.

The collaborative atmosphere encouraged participants to exchange ideas, ask technical questions, and explore different architectural approaches.

Overall, the event significantly expanded my understanding of Agentic AI and strengthened my confidence in developing cloud-native AI applications using AWS.

## Lessons Learned

- Agentic AI focuses on performing tasks rather than only generating responses.
- Amazon Bedrock provides a powerful foundation for enterprise AI applications.
- Cloud architecture remains essential for building scalable AI systems.
- AI projects should always begin with solving business problems.
- Security, scalability, observability, and cost optimization are equally important as AI model selection.
- Real-world demonstrations provide valuable insights that go beyond technical documentation.
